# 训练目的与能力地图（v1 → v3 → 远景）

> 本文档对齐"我们到底在训练什么、最终能得到哪些能力"。用于每次版本前确认方向。

---

## 一、训练目的（三层，自下而上）

### 目的 1：表示层——**数在潜空间是"值/整体"**
不是字形串（`1`,`1`,`9`,`6`,`2` 五个无关 token），而是一个**数值对象**。
- 实现手段：数字嵌入（NAVE，备选）/ 逐位绑定（`x := 1,1,9,6,2`，v3 主用）
- 判据：copy probe、宽度外推（无需重新训练就能处理更长的数）

### 目的 2：算法层——**分析型算法的长度无关性**
核心洞察（用户）：**只训 3~4 位，靠算法泛化到 N 位**。
- 逐位处理（每行宽度 1）、循环计数（i 从 1 到 k）、满十进位
- 判据：5/7/8/9 位外推（训练只到 4 位）

### 目的 3：交互层——**同一逻辑本体的多表面形式对齐（枢轴对齐）**
数学符号是**本体**，中/英/缩写/字形是**界面**：
| 通道 | 样例 |
|---|---|
| 符号（本体） | `s(a)=a+1`、`F := a+b`、`P := (a<b)`、`⊤`/`⊥` |
| 数字字形 | `4483` |
| 中文 | `四千四百八十三` |
| 英文 | `four thousand four hundred and eighty-three` |
| 缩写 | `5千`、`2k`、`3w`、`1.5万` |
- 判据：跨形式互译（中文问→符号答）、往返测试

## 二、能力清单（已验证 / 待验证）

### 🎯 两个核心业务目标（用户明确，2026-09-17）

| 目标 | v3 数据 | 算法 | 复杂度 |
|---|---|---|---|
| **① 学会加法** | [R2] 加法循环 4416 条 | 循环计数（i 从 1 到 k）逐位加 + 满十进位 | **O(位数)** |
| **② 会比较数值大小** | [R3] 序关系 3553 条 + L1/L2 序三态 | 后继循环 `a<b ⟺ ∃n≥1, sⁿ(a)=b` | **O(差值)** |

**两条路线的哲学差异（用户裁定"先学走再学跑"）**：
- 序关系**保留后继循环**（O(差值)）——它是**公理的本义**（"走"），先掌握"递归循环求值"这个模式
- 差值多大只是循环次数问题（`1<100万` 需百万次后继，但**时间问题不是能力问题**）
- 训练只用小差值（≤10，最多 10 行），避免超长样本（1060 字符 → 645）
- 评估时才测大差值（20~60），验证**能否递归推下去**（E6-R 递归泛化）
- 逐位比较（O(位数)）是**更快的推论**，留作后续版本的"跑"（v4+）

### ✅ 已验证（v1 / v2 实测）

| 能力 | v1/v2 实测 | 说明 |
|---|---|---|
| **公理套用（真泛化）** | **挖洞 100%** | `s(7777)` 训练删光实例仍答对 = 套公理非查表 |
| **序关系** | **外推 100%** | 五位数比较（纯符号操作，宽度无关） |
| **加法竖式算法** | **训练宽度内 100%** | 数位对齐→逐位加→进位→合成 |
| 训练宽度内后继/加法 | 100% | 1~4 位 |

### v3 实测结果（2026-09-18 完成）

| 能力 | 结果 | 判读 |
|---|---|---|
| **循环计数格式执行** | 3/4 位后继/加法 **100%** | ✅ 机制成立（迭代/进位/合成全对） |
| **宽度外推（核心）** | **0%**（5~7 位） | ❌ 新墙：**位数不可知** |
| **读法对齐** | 4 位中文 **100%** / 缩写→数值 **100%** | ⚠️ 部分成立（万级/反向受位数问题牵连） |
| **序三态** | ⊤ **100%** / ⊥ **0%** | ⚠️ 方向语义丢失 |
| 序递归泛化（差值 20~60） | **100%** | ✅ 公理循环能往下推 |
| 序宽度外推（5 位） | **100%** | ✅ 序不受位宽影响 |
| 挖洞后继 | **100%** | ✅ 公理套用保持 |
| 组合泛化 s(s(a)) | 0% | ❌ 同"位数"问题 |

**核心发现**：墙从"复制丢位"（v1/v2）**转移**为"**位数不可知**"（v3）。
循环格式解决了"每步宽度 1"，但循环上界 `k` 需要知道位数——而"位数"从未被显式训练。
详见 [`V3_SUMMARY.md`](V3_SUMMARY.md)。

### ⚠️ 已知边界（诚实标注，非承诺）

| 边界 | 原因 | 缓解 |
|---|---|---|
| **跨形式问答** | v1/v2 数据无"中文问→符号答"任务（L3 只是并列出现） | v4 加混合任务样本 |
| **组合泛化** | v2 实测 0%（4 层容量不足） | v3 已补量至 3500+800 条，观察 |
| **进位链串行深度** | 4 层 ≈ 3~5 步工作记忆 | v3 进位状态显式 token 化（`c:=1`）可能缓解 |
| **超长位宽（10+ 位）** | 序列长度 + 注意力跨度 | 未测；循环格式理论支持 |
| **读法-数值的双向泛化** | 是否只背了训练见过的读法 | 需测未见数的读法（如 4 位随机） |

## 三、能力阶梯（远景：从算术到现代数学架构）

当前 v3 仍处**算术层**。用户最终目标"从集合/群等现代数学认知开始训练"是一条阶梯：

| 层 | 能力 | 版本 | 状态 |
|---|---|---|---|
| L0 | 数字表示 = 值（非字形） | v3 | ⏳ |
| L1 | 分析型算术（加减，任意位数） | v3 | ⏳ |
| **L2** | **数系扩展：ℤ（负数/借位）、ℚ（分数/除法）** | v4 | 未开始 |
| L3 | 集合构造：ℕ→ℤ→ℚ 的等价类构造（`(a,b)~(c,d) ⟺ a+d=b+c`） | v5 | 未开始 |
| L4 | 代数结构：群/环/域的公理与推导 | v6 | 未开始 |
| L5 | 定理证明式推导链（机器验证正确性） | 远景 | 未开始 |
| L6 | 实数/完备性（柯西列/戴德金割切） | 远景 | 未开始 |

**每层的能力目标与判据**（供后续版本对齐）：

- **L2（v4 计划）**：负数（`-5`、借位减法、`s(-5)=-4`）、分数（`3/4`、约分）
  - 判据：负数后继/加减、分数等价类
- **L3（v5 计划）**：把 ℤ 定义为差等价类、ℚ 定义为商等价类——**这正是用户"集合方式描述数"的本体**
  - 判据：构造性推导链（`(3,5) ~ (1,3)` 因为 `3+3=5+1`）
- **L4（v6 计划）**：加法群公理（结合律/单位元/逆元）、环、域
  - 判据：公理套用（挖洞协议）

## 四、当前 v3 的"能力承诺"（本次训练的诚实预期）

**会得到的（高置信）**：
1. 1~4 位后继/加法的循环格式执行（~100%）
2. 序关系三态（⊤/⊥）在训练内 + 宽度外推（序是纯符号，v1 已证 100%）
3. 读法/缩写对齐（模板确定性任务，训练内应高）
4. 挖洞泛化保持（v1 是 100%）

**可能得到（待验）**：
5. **5/8/9 位外推**——本版本最大悬念，取决于循环格式是否真的长度无关
6. 组合泛化（`s(s(x))`）——4 层容量是瓶颈

**不会得到（已知未覆盖）**：
7. 跨形式问答（数据无此任务）
8. 英文/中文的"逻辑推理"（英文只做读法，推理链仍中文+符号）
