从沟通需求出发
为什么我们要研究语言模型？

先从沟通、协作和句子结构出发，再看 CNN、RNN 怎样处理词序，Transformer 又怎样用自注意力连接远处的信息。最后拆开 GPT：它如何读入一段话，并一步一步预测下一个 token。

本课目标：看懂一条句子从文本、token、向量、位置，到注意力与下一个 token 概率的执行路径；理解不同架构为何相继出现、各自解决什么问题。

1. 语言沟通：把对真实世界的理解传给别人

先想象一个人在河边看见了水。他脑中有“水在这里、可以饮用”的经验；如果要让同伴知道，他会把这份理解映射成大家共同使用的声音或文字符号——“水”。最早、最简单的词可以这样理解：一个 token 作为约定的符号，指向现实中的物质、对象、动作或状态。

说话者从自己对世界的理解出发，选择一个或多个 token 组成话语；听者接收这些 token，再根据共同语言经验把它们映射成自己脑中的概念和关系，进而行动、提问或回应。双方恢复出的意义可以接近，但不必完全相同。

用这个角度看大语言模型：它要从接收到的 token 序列中，构造对上下文有用的内部表示，再预测合适的后续 token，形成回答。模型的内部向量空间可以类比为它处理意义的“潜在表示空间”；但它与人的主观体验不是一回事，也不是我们能逐维翻译的词典。从功能目标看，大模型要尽可能学会听者的流程：接收符号、恢复上下文关系、形成可用于任务的内部表示，再组织出恰当回应；关键是能把学到的结构迁移到新组合，而非只背熟悉句子。

从“词指向现实事物”到“听者恢复意义”是本课的概念模型。现代 tokenizer 的 token 不一定是完整单词，也可能是子词、字符片段、空格或标点；这里先从最容易理解的词级符号开始。

2. 复杂协作催生结构，也带来早期的泛化

一句“老虎！跑！”能提醒危险，却不足以组织多人行动。协作需要说清谁执行、做什么、针对谁，以及如何做、哪一个目标、什么条件下行动。来看这句：

“你们去绕后包围那只正在喝水的大象。”

我们可以先把它拆成结构角色：

句子成分本句片段它补充了什么信息
主语 / 执行者你们谁来执行任务
谓语 / 核心动作包围要执行什么动作
宾语 / 目标大象动作作用于什么对象
状语 / 执行方式去绕后怎样、从哪里执行包围
定语 / 目标限定那只正在喝水的从多只大象中选出哪一只

这些词不是随便堆在一起。语法位置和连接方式让听者知道“你们”是执行者，“包围”是动作，“大象”是目标；状语和定语再把方法与目标补充清楚。得到的不是一串词，而是可以执行的一组关系。

这里出现了早期的泛化：听者不必把这整句话当成一条从未见过、必须整体背下来的声音。学会“谁—做什么—作用于谁”，再学会方式、时间、地点、条件等修饰关系，就能把熟悉的结构组合到新人物、新动作和新对象上。相同结构可以理解“你们去绕后包围那只正在喝水的犀牛”，即使整句以前没听过。

这提供了从语言结构走向神经网络架构的教学问题：如何在有限参数与计算下表示局部模式、顺序状态、长距离关系和组合结构？CNN、RNN、Transformer 是处理序列的不同答案。

3. 两句话贯穿本课：简单组合与复杂结构

简单句 I love you 用来认识基本数据通路。本地 tokenizer 把它切成 [I, Ġlove, Ġyou]，ID 是 [40, 2948, 498]；这些 ID 查 embedding 表，组成每个位置的向量，再注入位置线索。别的 tokenizer 可能有不同切法。

复杂句 你们去绕后包围那只正在喝水的大象 用来观察结构和泛化。下面先按语言成分展示，真实 tokenizer 会把中文按词或子词切分，边界未必与表格每格完全相同：

行动者你们
方式去绕后
核心动作包围
被限定的目标那只 + 正在喝水的 + 大象

神经网络看到的是按次序排列的 ID 和向量，不会自动拿到上面的中文语法标签。它需要从训练样本中学习哪些位置、词形和上下文经常共同表达主语、动作、宾语、方式、限定等关系。这就是后面比较架构时要追踪的问题。

现实/语境中的意义 → 说话者组织结构 → token 序列 → 模型内部向量与关系 → 预测回应 token

4. CNN：先组合邻近 token，再扩大感受野

把复杂句切成一个教学用的词序列：你们｜去｜绕后｜包围｜那只｜正在｜喝水｜的｜大象。真实模型 tokenizer 的切分可能更细。文本 CNN 用卷积核在相邻向量上滑动，共享同一套参数，生成局部特征。

CNN 可以抓到邻近词组模式，比如“正在喝水的”可能是名词的修饰语；卷积在各位置并行，局部模式参数共享。要关联句首“你们”和后面的动作“包围”，或把很长的限定语和“大象”绑定起来，需要更大的窗口、更深网络或其他结构。

局限不等于不能泛化：CNN 也能通过层叠和训练学习复杂组合，但局部感受野是它的信息路径偏置。对于更长的依赖，所需层数和路径长度可能增加。

5. RNN：沿着句子读，把未完成的结构带在状态里

仍读同一句。RNN 从左到右处理 token：先读“你们”，再读“去绕后”，然后读“包围”，接着读目标修饰语，最后读到“大象”。每一步用当前输入和前一状态更新隐藏状态。

hₜ = f(xₜ, hₜ₋₁)
读到“你们去绕后包围那只正在喝水的”时，状态需保留：谁执行？核心动作是什么？目标还没读完吗？

这个接力式过程有直观优势：读入顺序自然，输入可以流式到达。它的难点是所有时间步串行依赖，训练整句时不容易并行；而“谁执行、动作是什么、修饰哪一个目标”要压缩保存在有限维状态中，句子越长，早期信息越可能淡化或混淆。LSTM/GRU 的门控改进了长期记忆学习，但仍保留逐步递归。

图中 hₜ 里的文字是我们为了教学给状态贴的解释标签。实际 RNN 的隐藏向量不是显式字段，也不保证每一维恰好代表一个语法成分。

6. Transformer：让分散的词直接交换上下文信息

Transformer 让每个位置根据内容，为其他可见位置分配注意力。直观地看，理解复杂指令时可能需要把“你们”与“包围”联系起来，把“绕后”解释为包围的方式，再把“正在喝水的”绑定到目标“大象”。它不必让这些线索只能一站一站穿过隐藏状态传递。

数学上，每个位置的向量投影成 Query、Key、Value：Query 表示当前找什么，Key 表示当前位置如何被匹配，Value 是被取用的信息。点积产生匹配分数，softmax 变为权重，加权组合 Value 得到更新表示：

Q = XWQ，K = XWK，V = XWV
Attention(Q,K,V) = softmax(QKᵀ / √dₖ + mask) V

自注意力并不会收到人工标注的“主语”“定语”字段。它从上下文计算信息混合，多个 Transformer 层再逐步形成对任务有用的内部表示。若用 Decoder-only GPT 训练，causal mask 还会遮住当前位置右侧，防止预测时看到未来答案。

和 RNN 的关键区别：RNN 要把早先的“你们”信息逐步带到句尾；Transformer 每层都能让后续位置直接与前文多个位置计算相关性。训练时同一层各位置可以并行计算。代价是全注意力要处理很多位置对，序列变长时计算/显存变贵；而 GPT 的生成阶段仍需逐 token 输出。

注意力连线只说明架构允许这些位置交换信息。具体模型会分配什么权重，要看训练所得参数、输入上下文和层/头；模型是否正确分析句法，必须用任务与行为测试验证。

7. GPT：用自回归方式逐 token 生成回答

Transformer 是一类网络结构；GPT 是把 Transformer Decoder 用于生成式预训练的一条路线。模型读入左侧上下文，给词表里的下一个 token 计算概率。训练时把真实后续 token 当目标，让预测分布靠近正确答案；推理时选出或采样一个 token，接回输入，再重复预测。

同一机制也可从简单句看：给定 I，模型预测下一个 token；给定 I love，模型预测后续 token。训练输入与目标错开一位，因果遮罩保证每个位置只能利用它之前的内容。

面对复杂句，模型的内部层可能利用前文形成行动者、动作、方式和目标之间的关系表示，从而续写或回答；但 next-token 训练目标没有直接保证它一定形成正确的人工句法分析。是否具备可泛化的结构理解，需要设计新句式、换对象和换修饰语来测，而不能只看熟悉样本上的流畅度。

8. 三种架构看同一件事

结构读一句话时的信息路径显著优点典型限制
CNN固定窗口卷积；堆层扩大感受野局部模式强，位置间并行，参数共享远距离关系要靠扩大/堆叠感受野
RNN / LSTM按序读；隐藏状态向下一步传递天然顺序、适合流式处理，状态可固定大小时间步有串行依赖；长历史压缩在状态中
Transformer注意力让各位置按内容读取允许范围内的位置训练时序列并行；远处位置可直接联系全注意力长序列成本高；生成仍逐 token

它们不是简单的“旧架构都错、新架构全胜”。CNN、RNN 和 Transformer 对信息流动方式做了不同选择，适合的任务、延迟和内存约束也不同。理解这些选择，才能看懂 GPT 为什么采用 Decoder-only Transformer，也能判断何时需要卷积、递归状态或混合设计。

9. 前言回顾：为什么要研究语言模型

  1. 语言把共同约定的符号组织成有顺序、有关系的序列，支持传递信息与协作。
  2. 文本先经过 tokenizer 成为 ID，再通过 embedding 变成向量；模型还需表示位置。
  3. CNN 以局部窗口提取模式；RNN 按序传递隐藏状态；Transformer 用注意力让位置直接读取上下文。
  4. GPT 是 Decoder-only Transformer 的自回归语言模型，核心训练目标是预测下一个 token。
