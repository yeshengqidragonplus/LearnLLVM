# 从零预训练学习实验

这是我的公开学习记录：从随机初始化的小型 Qwen2 模型开始，在 RTX 4060 Laptop 和 RTX 4070 Laptop 两台电脑上探索数学数据、训练、评估和泛化。记录成功结果，也保留失败样例、判断修正与复现限制；后续用于制作自己的训练过程视频。

- **开始实验**：[安装与运行说明](pretrain_lab/README.md)
- **学习与经验**：[实验总册](大模型预训练学习与实验架构方案.html)（下载后用浏览器打开；原始记录折叠收录）
- **结构化计算研究设想**：[先组织结构，再执行计算](大模型预训练学习与实验架构方案.html#structured-computation)（待验证，不代表已实现）

所有代码集中在 `pretrain_lab/`。每台电脑各自安装 `.venv`，代码通过 Git 同步；运行设备和精度可选择，CUDA 支持 BF16 时自动使用 BF16，CPU 使用 FP32。

| 运行环境 | 当前状态 |
|---|---|
| Windows / RTX 4070 Laptop | CUDA 与 CPU 路径已在本机做小规模验证 |
| RTX 4060 Laptop | 使用同一入口，待在另一台电脑运行自检确认 |
| Linux / NVIDIA 或 CPU | 提供跨平台安装入口，尚未实机验证 |
| macOS | 提供 CPU 路径，尚未实机验证；未启用 MPS |
| AMD / Intel GPU | 尚未适配加速，可尝试 CPU 路径 |

兼容性仍受 Python、PyTorch wheel、操作系统、显卡驱动和内存影响。小规模自检通过并不保证完整训练都能装进显存。

当前保留现代数学 v5 / NAVE 实验链路；当前生成器 59,078 条与历史 v5-C1 的 94,942 条不同，不能视作该历史实验的精确复现。历史模型权重未随仓库提供。
