# v4-A 决定性发现：墙在最底层"复制通道"（定宽电路）（2026-09-19）

## 结论：真根因不是"位数不可知"，是复制通道定宽

v4-A 加了"数位数"层（把位数从隐含变显式），结果：
- 数位数 **1~4 位 100%，5~8 位 0~16.7%** —— 数位数本身没泛化
- 后继/加法 5~6 位仍 0%（墙未动）

### 三层结构（修正 v3 的单层假设）
```
表象：位数不可知（循环上界 k 输出错）
  ↑
中层：绑定行复制丢位（数列 L := 9,4,6,2 —— 5 位只抄了 4 个）
  ↑
底层：复制/读取通道是【定宽电路】——训练 1~4 位就只能复制 4 位
```

### 决定性证据（纯复制探针）
```
问: 抄写 4483  → 4483  ✅
问: 抄写 94692 → 9492  ❌（第 3 位 6 消失）
```
连"抄写"5 位都做不到。数位数的计数逻辑完全正确（`i=1(9),i=2(4)...`），
但**它的输入（数列）已丢位**——所以数位数破不了墙：第一步就是复制。

### 序关系退化
v4 新增的 `a>b` 模板被错误套用到 `a<b`（`1619<1629` 答 ⊥）→ v3 的 ⊤ 从 100% 掉到 33%。
教训：**新增模板会污染旧模板**（同任务多模板需防混淆）。

### 65M/4 层无 ICL
ICL 探针（给 3 个示例）全乱 → **小模型无法靠 in-context 验证新格式，必须专门训练**。

## v5 方向：化简不搬运（用户原设计）
用户 2026-09-17 原话："先把数字简化成 a 或 x 这样代数，整个输入的语句先做一遍处理，
化简成最简语义，然后再渐进展开"。
关键修正：**化简步不应搬运数字**（那是复制）。应"绑定符号 + 逐位查读"：
```
理解: 算式 F, F := a+b（a 为输入第 1 串，b 为第 2 串）   ← 不写数字
算法: i 从 1 起，从右往左读 a_i 与 b_i，直到两串都取完   ← 结构性停止条件
i=1: a_1=2, b_1=2, 2+2+0=4, 写4进0
i=4: (a 已取完), b_4=2, 0+2+0=2, 写2进0
```
三关键：①无一行写完整数字 ②停止条件结构性（绕开"位数不可知"）③越界显式化。
**风险**：位置查读能否跨长度泛化——v4-A 不能证明不行（查读从未单独训练）。

## 方法论价值
1. 证伪"位数不可知是根因"（真根因更底层）
2. 证伪"数位数天然宽度无关"（第一步就依赖复制）
3. 确认序方向修正有效（⊥ 0% → 50~83%）
4. 分层枚举有效（数据 -22%、时长 -79%、训练内能力保持）
5. 小模型探针方法受限（无 ICL），关键问题必须专门训练验证
